# Устойчивость двухуровневого управления ресурсами микросервисов при переменной нагрузке

Запрос пользователя в микросервисном приложении проходит через несколько сервисов, а процессорное время Kubernetes выделяет каждому из них отдельно. Контроллеры ресурсов, например Autothrottle (NSDI 2024), переводят общую цель по задержке в лимиты CPU для отдельных сервисов. При этом они опираются на метрики, которые приходят с опозданием, и меняют лимиты через фиксированные интервалы. При резком скачке нагрузки такой контроллер может отреагировать поздно или начать раскачиваться, то повышая, то снижая лимиты.

Цель работы — измерить этот эффект на стенде из нескольких связанных сервисов. Двухуровневый контроллер сравнивается с постоянными лимитами CPU при ступенчатой, импульсной и волнообразной нагрузке. Сравнение идёт по хвостовой задержке (P95/P99), нарушениям SLO, расходу процессорного времени и частоте изменения лимитов. Подробная постановка задачи — в [docs/postanovka_zadachi.md](docs/postanovka_zadachi.md).
