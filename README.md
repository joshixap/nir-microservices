# НИР / ВКР: управление ресурсами микросервисов

Рабочий репозиторий НИР Шитова Ивана. Научный руководитель — Бусько Илья Владимирович.

**Предварительная тема:** исследование устойчивости двухуровневого управления ресурсами микросервисов при переменной нагрузке. Подробно — в [docs/postanovka_zadachi.md](docs/postanovka_zadachi.md).

> В репозитории только публичные материалы: найденное в открытом доступе, собственный код, конспекты и тексты, подготовленные с помощью LLM. Все конспекты — в Markdown.
