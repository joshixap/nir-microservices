# Как выложить репозиторий на GitHub (приватно) и добавить руководителя

Локальный git-репозиторий в этой папке уже создан. Осталось три шага.

## 1. Создать пустой приватный репозиторий

1. Откройте https://github.com/new.
2. Имя: `nir-microservices`. Видимость: **Private**.
3. Не добавляйте README, `.gitignore` и лицензию — они уже есть локально.
4. Нажмите **Create repository**.

## 2. Отправить материалы

В терминале в папке `nir-microservices` (подставьте свой логин):

```bash
git add .
git commit -m "Задание 1: история и особенности микросервисов"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/nir-microservices.git
git push -u origin main
```

## 3. Добавить Илью Владимировича

1. В репозитории: **Settings → Collaborators → Add people**.
2. Введите его логин на GitHub или email. Его нужно уточнить у него самого.
3. В личном репозитории приглашённый сразу получает права на запись.
4. Он получит приглашение на почту и должен его принять.
